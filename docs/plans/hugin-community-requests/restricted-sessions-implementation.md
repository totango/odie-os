## Execution and enforcement

1. Reservation/receipt is local and atomic; a wakeup is armed before accepted work is acknowledged. Constructor does not postpone an existing due alarm. Registry arbitration retains earlier ordinary work and includes restricted deadlines.
2. Private backend authorization is called at reserve/start/collection; model forwarding reauthorizes separately. The decision must match the exact immutable intent hash/session/generation. Local metadata also fences stale generations and cancellation.
3. One deployment-wide slot lives in the existing registry namespace's reserved `.request-build-capacity` instance. It has no time-based expiry that could release capacity while a process survives. Destruction must finish before the exact owner/key releases the slot. Backend stage C still owns logical per-request run uniqueness.
4. Clone and runner/collector launch intent is persisted before `exec`. A lost start response, vanished process, stale generation or uncertain operation becomes `needs_attention`; no second exec is launched against an ambiguous attempt. Explicit backend retry must allocate another attempt after cleanup; personal restart cannot replace this generation.
5. Fixed-repository Git smart HTTP allows only `info/refs?service=git-upload-pack` GET and `git-upload-pack` POST. A contents-read-only repository-scoped installation token stays in the Worker policy; caller headers/cookies are discarded, redirects and receive-pack/other repos deny. No GitHub publisher token is present in the sandbox.
6. Dedicated class outbound handlers are registered separately (the installed Containers registry keys handlers by class name). Internet is disabled; only configured vetted dependency reads and the existing exact model relay are allowed. Dependency redirects/authentication headers deny; Workshop MCP/catalog denies even on a direct policy call. Ordinary outbound maps remain unchanged.
7. Every model request reserves a call and the policy's conservative maximum per-call charge synchronously **before** fetch. No timeout/error refund. Input bytes, model ID, output-token cap, hosted-tool/background/previous-response features and response bytes are enforced. Numeric spend is a conservative reservation ledger, not an independently measured provider invoice: activation must verify that the approved per-call charge really upper-bounds the chosen provider/model at these input/output limits. It must not treat arbitrary configured pricing as evidence.
8. Remote exec timeouts use remaining absolute wall time; the runner has its own bounded timer and output-event limit; registry deadline cleanup disables egress before destruction. Frozen diff/output bounds reject overflow rather than silently truncate. Artifacts are immutable **untrusted patches**, not publisher-approved trees: stage C must independently validate base/hash/paths/file modes/content and publish without executing generated code.
9. Cancellation is monotonic, service-owned and independent of a revoked initiator's current eligibility. Cleanup has a separate persisted status, retries after failure and retains capacity. Error receipts/logs contain closed codes/correlation IDs, not raw request/provider content.
