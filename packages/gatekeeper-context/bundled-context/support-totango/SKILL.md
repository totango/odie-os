# Totango support workflow

Use this skill for Totango account-health, success journey, segment, task, and product-usage questions.

1. Clarify the business question and timeframe.
2. Prefer approved knowledge-graph or read-only business context tools for account, CSM, health, and usage facts.
3. Summarize trends and likely explanations; do not expose raw private records.
4. If data is incomplete, list precise follow-up checks rather than guessing.
5. Provide a customer-safe recommendation and an internal next action.

Keep outputs concise and avoid importing private identifiers, case records, or local file paths.
