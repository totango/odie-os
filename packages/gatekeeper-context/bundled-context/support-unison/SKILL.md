# Unison support workflow

Use this skill for Unison integration, usage reporting, activation, and analytics questions.

1. Clarify the metric or workflow the requester expects to see.
2. Check source freshness, integration status, and transformation assumptions before concluding product behavior is wrong.
3. Compare aggregate counts and trends rather than exposing row-level private data.
4. Name likely causes with confidence: delayed sync, mapping mismatch, permission, filter, or product issue.
5. Provide next checks and a customer-safe summary.
