# Integration support notes

When troubleshooting integrations, validate in this order:

1. Connector is enabled and authorized.
2. Source system has recent successful activity.
3. Field mappings and filters match the expected object set.
4. Sync schedule or webhook delivery is current.
5. Reporting view uses the same timeframe and definition as the requester.

Escalate with sanitized reproduction steps, observed timestamps, and aggregate impact.
