# Catalyst support workflow

Use this skill for Catalyst-style customer success operations, workflow, playbook, account view, or configuration questions.

1. Identify the workflow object involved: account view, playbook, task, lifecycle stage, alert, or integration.
2. Ask what changed recently: configuration, permissions, sync cadence, field mapping, or rule criteria.
3. Compare expected behavior with the active rule or workflow definition.
4. Offer a reversible next step before recommending destructive changes.
5. Write customer-facing updates without private identifiers or internal-only labels.
